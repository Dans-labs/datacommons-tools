# UI for the EOSC DataCommons Tool Registry API

React + TypeScript + Vite application using OIDC authentication.

## Configuration

For development, copy `.env` to `.env.development` and edit accordingly.

For production builds, use `.env.production`.

## Running

Install dependencies:
```bash
npm i
```

Start development server:
```bash
npm run dev
```

Build static files:
```bash
npm run build
```
